Pair this browser

Only browsers you pair can see Polymath, and only on your home network.

  1. Get a code: the installer showed one, or run polymath access pair on the Pi (or over SSH). A paired browser can also make one: the dashboard's Who can see this panel.
  2. Type it here. The code works once and lasts 15 minutes.

Remove Chrome's warning (optional, once)

The connection is encrypted with a certificate the Pi made for itself. Chrome warns because it does not know the Pi yet. To make Chrome trust it on Windows:

  1. Download the Pi's certificate and open the file.
  2. Check that its thumbprint (Details tab) matches the one below.
  3. Choose Install Certificate… → Current User → Place all certificates in the following store → Trusted Root Certification Authorities → Finish, then restart Chrome.
